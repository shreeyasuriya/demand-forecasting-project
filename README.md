# Demand Forecasting Using Machine Learning

## Project Overview

This project builds a demand forecasting system using Python and Machine Learning. The goal is to predict product demand based on factors such as price, discount, inventory levels, promotions, competitor pricing, and product category.

The project includes data analysis, feature engineering, model training using XGBoost, and deployment of an interactive web application using Streamlit.

---

## Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering
* Label encoding for categorical variables
* Machine Learning model using XGBoost Regressor
* Model evaluation using MAE and RMSE
* Interactive Streamlit web application for demand prediction

The model was evaluated using:
